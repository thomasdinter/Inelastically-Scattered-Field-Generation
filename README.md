# Inelastically-Scattered-Field-From-a-Levitated-Dipolar-Scatterer
This is the code used in Thomas Dinter's Masters of Research thesis and the corresponding paper (pre-print available at: https://doi.org/10.48550/arXiv.2409.08827).

The code is used to:

**(1)** Find the complex-valued electric field inelastically scattered from each translational degrees of freedom of a levitated dipolar scatterer, in the focal plane of some aplanatic collection lens and having been transformed by a high numerical aperture (NA) parabolic mirror.

**(2)** Estimate the coupling efficiency of each inelastically scattered field component to several low-order modes of the LP mode basis of a few-mode optical fiber.
